Five new Java skills cover the back-end pieces a module writes besides an action: `jahia-java-render-filter` (conditions, priority and the HTML cache, `finalize`, encoding), `jahia-java-choicelist-initializer` (keys, labels per locale, keys and values of content in production), `jahia-java-validator` (Bean Validation on save, translated messages, the save paths that skip it), `jahia-java-graphql` (schema extensions, `@GraphQLRequiresPermission` on `/`, API scopes) and `jahia-java-permissions` (`permissions.xml`, `roles.xml`, the node each check reads). Each example was built and deployed on Jahia 8.2.3.4. `jahia-dev-java`, `jahia-review-java`, `jahia-java-security` and `jahia-dev-migrate-jsp` point to them.
